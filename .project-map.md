# Project Map

> Navigation cache. Source files are authoritative.

## Project
IslamTrove is an Nx monorepo for an Angular Quran listening studio and a FastAPI audio, text, alignment, and administrator-review backend.

## Areas
- `frontend/src/features/listening-studio/` — listening configuration, passages, playback, and UI; entry: `components/player/app.component.ts`.
- `frontend/src/application/ports/` — typed feature-to-infrastructure contracts; concrete implementations in `frontend/src/infrastructure/adapters/`.
- `frontend/src/infrastructure/media/` — hot/persistent media caching and registration; browser range worker: `frontend/src/stream-cache-sw.js`.
- `frontend/.design/` — Design Canvas managed-v2 feature/page/port ownership: `project.json`.
- `backend/src/islamtrove/api/` — Quran endpoints, streaming, continuous timing, text, and review administration.
- `backend/src/islamtrove/application/` — provider orchestration and review overlays.
- `backend/src/islamtrove/data/alignments/` — packaged, source-specific original Ayah timelines (`NNN.json`).
- `backend/review-data/` — source-hash-pinned verified/corrected Ayah records and audit history (`NNN.json`).
- `backend/scripts/offline-audio-alignment/` — corpus generation and audits, separate from runtime.
- `.woodpecker/` — two independent main-branch Docker deployment pipelines.
- `docs/` — focused playback, cache, source, and deployment references.

## Ownership
**Frontend**
- `frontend/src/main.ts` — composition root: selects mock vs production adapters and injects ports into Angular.
- `frontend/src/features/listening-studio/components/player/app.component.ts` / `app.component.html` — reading/listening UI, settings and per-Ayah controls.
- `frontend/src/features/listening-studio/listening-controller.ts` — sequence vs single-clip playback, state and transitions.
- `frontend/src/features/listening-studio/audio-plan.ts` — Arabic/translation phase sequencing and passage order.
- `frontend/src/features/listening-studio/media-playback.ts` — decoded/streaming media player, gap handling and timing guards.
- `frontend/src/infrastructure/adapters/production/continuous-recitation/index.ts` — backend timeline loading/cache.
- `frontend/src/infrastructure/adapters/production/alignment-review/index.ts` — admin review API and session interaction.
- `frontend/src/infrastructure/media/register-stream-cache.ts` / `frontend/src/stream-cache-sw.js` — worker registration and range-cache behavior.
- `frontend/src/environments/environment.ts` / `environment.production.ts` — mock preview vs real API selection.

**Backend**
- `backend/src/islamtrove/main.py` — FastAPI composition, HTTP clients, settings, review store/session wiring and local-preview CORS.
- `backend/src/islamtrove/api/continuous.py` — reads/validates canonical source-specific timings and exposes continuous recording metadata.
- `backend/src/islamtrove/api/stream.py` — allowlisted progressive/range audio proxy.
- `backend/src/islamtrove/api/verses.py` — Arabic and written-translation HTTP routes.
- `backend/src/islamtrove/api/alignment_admin.py` — admin login, same-origin/HTTPS/CSRF enforcement and review write endpoints.
- `backend/src/islamtrove/application/alignment_review.py` — durable review JSON, SHA-bound corrections and effective timeline overlay.
- `backend/src/islamtrove/application/quran_service.py` — catalog/legacy media use cases.
- `backend/src/islamtrove/infrastructure/quranenc_text.py` — independent written translations; Urdu Jalandhari `ur.jalandhry` via Al Quran Cloud, without Junagarhi fallback.
- `backend/src/islamtrove/core/settings.py` — runtime settings, including administrator password environment value and review directory.

**Deployment**
- `backend/Dockerfile` / `backend/docker-entrypoint.sh` — non-root FastAPI runtime; seed *missing* review JSON without replacing live files.
- `frontend/Dockerfile` / `frontend/nginx.conf` — static Angular hosting and same-origin `/api/` reverse proxy.
- `.woodpecker/backend-pipeline.yml` / `.woodpecker/frontend-pipeline.yml` — build, replace running container, remove stale images; backend provisions host review directory through a temporary container.
- `docs/DEPLOYMENT.md` — host bind mount, Woodpecker secret and TLS proxy setup.

## Routes & Flows
- **UI design or mock preview** → `frontend/.design/project.json` → `frontend/src/main.ts` → `frontend/src/features/listening-studio/components/player/app.component.ts`; mock data in `frontend/src/infrastructure/mock-data/`.
- **Shareable Surah deep links** → `frontend/src/features/listening-studio/shared-listening-link.ts` (generate/validate URLs) → `app.component.ts` / HTML (Share button, copy/native share, apply link settings, autoplay fallback); Design Canvas keeps `/?link-demo=blocked` artboards.
- **Surah/passage listening** → `listening-controller.ts` → `audio-plan.ts` → `media-playback.ts`; source adapters resolve independent Arabic recording and spoken translation.
- **Personal grouping persistence/presets** → `frontend/src/features/listening-studio/components/player/app.component.ts` (per-Surah breakpoints in browser `localStorage`) → `passage-presets.ts` (hardcoded Al-Kahf starter) → `audio-plan.ts` (normalization/passage construction); server-published grouping API implemented.
- **Grouping library and publication** → normal Listening summary **Groupings** button / Settings tab in `app.component.ts` → `grouping-library-preview.component.*` → `GROUPING_LIBRARY` port → mock/production adapters → public `api/groupings.py` and admin single-Surah POST → `application/grouping_store.py` → host-mounted `review-data/groupings.json`. Design Canvas artboards remain at `/?groups-demo=local|server|publish|success`; see `docs/GROUPINGS.md`.
- **Long audio buffering** → `frontend/src/infrastructure/adapters/production/streaming-source/index.ts` → `backend/src/islamtrove/api/stream.py` → `frontend/src/stream-cache-sw.js`.
- **Timeline correctness** → `backend/src/islamtrove/data/alignments/` → `continuous.py` → `alignment_review.py` → `frontend/src/infrastructure/adapters/production/continuous-recitation/index.ts`.
- **Administrator review/correction** → `frontend/src/infrastructure/adapters/production/alignment-review/index.ts` → `alignment_admin.py` → `alignment_review.py` → `backend/review-data/`.
- **Deployment or persistence** → `docs/DEPLOYMENT.md` → `.woodpecker/`, `backend/docker-entrypoint.sh`, `frontend/nginx.conf`.

## Invariants
- Arabic base alignments and review overlays have **different ownership**: never silently rewrite base `alignments/NNN.json` when verifying an Ayah.
- Browser calls to production API are same-origin `/api/*`; the Docker backend has no published host port.
- Large original source recordings are streamed, not generated or included in Git/container images.
- `frontend/.design/project.json` governs Design Canvas ownership; actual Angular source/config is authoritative for runtime behavior.
